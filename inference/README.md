# 实际推理端源码

此目录预留给服务器 / 比赛机器当前实际使用的推理实现。当前尚未上传推理代码。

请由推理端同步实际启动入口及其项目内依赖，优先包含：

- `backends.py`：输入字段、姿态、高度、搜索窗与候选尺度的转换。
- `utils.py`：候选生成、检索排序、SGVA、匹配及坐标回映射。
- `DINOv2_Shared.py`：模型构建、checkpoint 加载、GeM、dense / CLS 返回值。
- `feature_extract.py`：query / gallery 预处理、特征提取和缓存。
- `naviParams.example.txt` 或其他参数示例：保留字段、单位及默认约定，去掉凭据和机器私有路径。
- 项目内其他必要模块、入口说明、依赖版本说明，以及所用源码 / 权重的身份记录。

保持推理项目内部的相对目录结构，在此说明中补充从哪个工作目录启动。训练工程仍在仓库根目录；暂不为适配仓库布局改写运行逻辑。

不要上传环境、模型权重、真实图像、地图、DSM、缓存或输出。现有 `reference/scc_snapshot/` 仅供比较，不能用它代替实际部署版本。

同步后先按 [训练推理对齐清单](../docs/训练推理对齐.md) 提交核验结果。当前训练默认配置中所有未确认标记继续保留。
