# 垂直（DV/NV）推理 .so 更新说明（2026-11-07）

垂直和倾斜用同一份推理源码，分别编译两个 .so；区别只在 `naviParams.txt` 和检索头权重。本包的 `naviParams.example.txt` 是垂直配置。垂直训练和检索头不变，继续使用现有的 `scc_retrieval_head.pth`。

## 一、相对服务器 e 版的推理改动

| 内容 | 对垂直的影响 | 文件 |
|---|---|---|
| **PnP 一致性检验 + 检索位置回退**（本次新增） | PnP 结果须落在它所匹配的检索块内（0.75 × 块边长），且高度与先验相差 ≤ 300 m；所有候选都不一致时，输出前几名检索块（得分加权）换算的位置，置信度 0，不用于跟踪 | `consistency.py`、`backends.py` |
| 偏移模型跟踪 `offset_model` | 先验误差为固定或缓慢变化时：跟踪中心 = 当前先验 + 最近一次定位的偏移量 | `prior_tracker.py` |
| 定位失败打印堆栈；`[RETRIEVAL_TOP]` 打印检索前 5 名经纬度 | 只增加日志 | `backends.py` |
| 倾斜专用功能（`oblique`、`query_crop_scale`） | 垂直配置不写这两项，行为与原来完全相同 | `oblique.py` 等 |

## 二、一致性检验与回退的效果（模拟）

S 形航线、先验为缓慢漂移的 3–4 km 偏移、AGL 1000 m、检索正确率 70%，统计误差 ≤ 150 m 的帧比例：

| 检索正确时 PnP 也正确的比例 | 原方案 | 只做检验 | 检验 + 检索回退 |
|---|---|---|---|
| 0.8 | 0.60 | 0.71 | 0.71 |
| 0.6 | 0.40 | 0.53 | 0.54 |
| 0.4 | 0.21 | 0.31 | 0.31 |

开着跟踪时，主要收益来自检验：错误的 PnP 结果不再被输出，也不会把跟踪带偏，失败帧改为输出预测位置。检索回退主要在捕获前或关闭跟踪时起作用：每帧真值都在窗口内且关闭跟踪时，得分从 0.43 提高到 0.70。

检索位置的误差约为 0.13 × AGL（网格间距的一半），AGL 高于 `max_fallback_agl`（默认配置 1200 m）时不回退。

## 三、编译与配置

```bash
cd inference/single-so
bash rebuild_from_old_so.sh /path/to/old/libvNavigatorInterface.so
python3 tools/extract_runtime.py dist/libvNavigatorInterface.so /tmp/rt.tar.gz && tar -xzOf /tmp/rt.tar.gz --wildcards '*consistency.py' | grep -c check_fix   # > 0
```

`naviParams.txt` 的 `infrared` 段见 `naviParams.example.txt`，其中新增的两项：

```yaml
  tuning: {min_result_inliers: 15}
  consistency: {enabled: true, block_ratio: 0.75, altitude_m: 300, retrieval_fallback: true, max_fallback_agl: 1200}
```

其余项（`reference`、`camera`、`prior_tracking`、`retrieval_head`）沿用当前垂直配置；`prior_tracking` 里加上 `offset_model: true`。

## 四、日志与回退

| 日志 | 含义 |
|---|---|
| `[PNP_CHECK] rank=.. inliers=.. ok/outside_block/altitude dist=..m dz=..m` | 每个候选的检验结果 |
| `[FALLBACK] frame=.. retrieval position` | 本帧没有一致的 PnP 结果，输出检索位置 |
| `[PRIOR_OUT] source=retrieval` | 捕获前输出检索位置；跟踪中会输出 `predicted` |

- 如果几乎每帧都是 `altitude` 且 `dz` 接近同一个值，说明 PnP 高度与先验高度的基准不同，把 `altitude_m` 调大（例如 600）。
- 如果正确结果被大量判为 `outside_block`，把 `block_ratio` 调到 1.0。
- 完全关闭：`consistency: {enabled: false}`，行为与原来相同。
