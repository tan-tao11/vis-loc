```

day_IR_vertical.txt
night_IR_slant.txt
```


## 二、数据集目录结构


```
data/
├── day/
│   └── IR/
│       ├── slant/
│       │   ├── sequence1/
```

## 三、四组数据的参数

表格从左至右分别对应：

- DS：day-IR-slant
- DV：day-IR-vertical
- NS：night-IR-slant
- NV：night-IR-vertical
