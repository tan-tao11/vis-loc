# SCC-Loc 接入与一致性边界

已核对附件 `reference/scc_snapshot`，未获得当前比赛机器的 backends.py、naviParams.txt 或用户手改缓存版本。此处是可调用的适配器和针对附件快照的补丁，不是未知 .so 的二进制修改。

## 精确接入点

`integration/feature_extract.snapshot.patch` 修改 `feature_extract.extract_features`，末尾增加可选 `retrieval_head=None`。query 的 `model(UAV1, return_dense=True)` 后仅将 `uav_global_feat` 传给 IR head；gallery 的 `model(batch_images, return_dense=True)` 后仅将 `sat_global` 传给 satellite head。禁用时返回原张量，原行为保留。

在初始化阶段构造一次 `RetrievalAdapter`：

```python
from integration.retrieval_adapter import RetrievalAdapter
adapter = RetrievalAdapter(
    filename='/absolute/path/scc_retrieval_head.pth',
    enabled=True, device='cuda:0',
    expected_backbone_hash='实际部署 checkpoint 的 SHA256',
    expected_preprocess_pose='导出 JSON 中经人工核验的指纹',
    allow_fallback=False,
)
```

对附件 `utils.py` 的 `retrieval_all` 中调用增加 `retrieval_head=adapter`，由初始化对象传递 adapter，避免每帧读权重。不要从训练代码 import SCC utils；它会引入整套匹配、可视化等依赖。

SGVA 的 `uav_cls_token`、`sat_dense` 均保持原始 1024 维，仍计算 CLS×dense 热图。512 维特征只用于 `gf @ qf` 排序。共享 DINOv2 权重、MINIMA-RoMa 和 matching 路径不改变。补丁没有替换 `DINOv2_Shared.py`；它的 p 在推理默认等于 4，训练代码以固定 float32 p=4 复现。

## 共享预处理

`preprocess.query_image` 实现快照中的整数中心方形裁剪、PIL 双三次 336 resize、显式强度映射和三通道复制；`geometry.camera_rotation` 实现 EO / 非 EO 分支；`geometry.reference_angle` 用图像右轴、完整卫星仿射和 WGS84/ECEF 投影求每帧角度，下视时不使用光轴方位角。

`preprocess.rotation_affine`、`local_rotated_crop` 等价实现 PIL expand 旋转后裁块；`candidate_image` 再使用 OpenCV LINEAR resize。已写方向、逆变换、非直角插值对照测试。PIL 和 OpenCV 旋转矩阵涉及角点与像素中心的区别，不能拿快照返回的 cv2 矩阵直接认为是逐像素精确的 PIL 采样逆变换。新共享模块返回的是 **PIL 角点坐标**逆变换。匹配点若为整数像素中心索引，应先加 0.5、应用逆矩阵、再减 0.5。几何 GeoTIFF 仿射本身采用角点坐标。

候选搜索策略是显式先验搜索窗、原生卫星分辨率、多尺度/高度偏差，不使用验证或测试 GT 插入候选。快照 `resolution_size` 使用 `cam_size/focal_len/rel_height/pitch`，这些字段如何由接口转换在缺失 backends.py 中；本工程不能证明候选尺度/搜索窗与比赛机器完全一致。正式训练前需将部署切到同一个共享候选协议，或用实际部署字段补全 adapter 并回归验证，才能确认 `deployment_confirmed=true`。

快照 `dumpRotateImage` 会把非 uint8 强转 uint8。本工程对 uint16/float 强制配置范围，**不会保留溢出截断**。如果真实输入非 uint8，必须同步修改部署强度映射并重新验证。配置中 false 表示上述一致性尚未确认。

检索评估的图块必须来自排序前原候选。`utils.py` 排序后按 SGVA 修改中心与尺度，后续保存的 matching 图块不能代替检索打分图。本工程 manifest 保存原候选 box、逆变换、足迹和唯一 ID，诊断图使用这些原始图块。

## Orin / .so

向 Orin 只移交导出 `.pth`、`models.py`、`common.py` 和 `integration/` 所需加载器；预处理若采用新共享协议，还需对应实现及配置。Windows CUDA 环境不能迁移到 Jetson。当前加载器使用 `torch.load(weights_only=True)`；目标版本不支持时应升级或做明确的兼容迁移并测试，不能静默退回不受限 pickle。旧 .so 若没有加载入口，需要重新集成或修改允许的 Python 缓存逻辑；单独复制权重不会自动生效。

在目标设备用同一批固定 1024 维输入保存 Windows/Orin 两端结果，核验两个头的最大绝对误差和排序一致性。缺文件、架构错误、backbone 或预处理指纹不符默认抛错；只有显式 `allow_fallback=True` 才警告并回退到 GeM1024。合成演示权重带 `synthetic_only=true`，生产默认拒绝加载。
