# 数据、几何与训练约定

实际资料只有参数样例和源码快照，没有真实图像、四个多帧 TXT、DSM 或当前 backends.py。目标驱动后续由用户提供为 527.27，尚未在目标机实测。示例 number=1000 不表示样本数，也不能复制为全组遥测。

## 遥测与姿态

支持表头 CSV/TSV 和逐行 `key=value` / `key:value` 多帧块，`number` 开始下一帧。逐图 TXT 要求同 stem、单条记录、帧号一致。多帧文件必须有 sequence 列，或配置 `sequence_by_file`。映射不明确、重复、别名冲突、越界、未匹配条目均进入报告，并阻止正式制标签。四组都是 imgType=0；isEO 是转塔标志，并按记录校验，绝不把它用作 RGB/IR 标志。

角度单位为度；NED、主动列向量旋转、候选 ZYX 顺序。EO 仅乘 INS 姿态和像素安装矩阵；非 EO 乘 INS、固定安装、sensor 欧拉角、像素安装。drone 角不会重复相乘。角度图支持候选零位光轴关系，但不足以确认完整像素轴、绕光轴偏角或全部欧拉约定。必须人工校准固定版本，禁止按每帧测试 GT 搜索最佳安装矩阵。

本工程正式标签由 `mapping_confirmed`、`calibration_confirmed`、`vertical_confirmed`、`deployment_confirmed` 共同控制。合成测试保留 false 并使用独立 `synthetic=true` 标记。不要为了让真实训练通过而未经核验修改这些标志。

## 地形与坐标

卫星需要米制投影 CRS；DSM 可以使用不同 CRS/分辨率，包括地理坐标系。均独立读取 CRS、仿射、NoData 和单位。外部 TFW 使用 A,D,B,E,C,F，中心点转换到角点时减半个行/列向量。先以 `GEOREF_SOURCES=INTERNAL` 读内嵌数据，再显式比较旁文件，避免 GDAL 静默覆盖。默认冲突中止，也可明确指定 embedded/sidecar。

高度是正常高。配置 `dsm_unit_to_m`、`dsm_to_platform_offset_m` 和 `normal_to_ellipsoid_m`；后一项是局部正常高到椭球高的高程异常，用于 ECEF 射线。当前实现固定局部偏移，不内置高程异常格网；区域过大或偏移变化不可忽略时，需要增加经纬度相关转换器并验证。真实基准未知时不允许默认 0。

内参依据实际宽高与每帧 FOV 计算，或用 K 覆盖。射线使用裁剪对应的原图像素坐标，因此中心裁剪/resize 不会丢失 K 的坐标关系。默认部署兼容路径不支持仅训练使用的去畸变/透视矫正；非零畸变配置会报错。可使用已校正且与部署一致的图像和 K。

ECEF 射线沿路径采样 DSM，遇到第一处地面交会后二分求根。光轴水平/向上、NoData、越界、无交会、退化足迹均拒绝并记原因。边界加密采样；DSM 步长要按地形细节调整，离散 marching 不能保证捕捉小于步长的尖峰遮挡。候选在卫星原生网格取窗，不按 DSM 分辨率降采样。有效区由 NoData 掩码保守腐蚀得到，覆盖面积不含无效插值支持区域。

## 标签与划分

coverage = 有效候选与查询足迹交集面积 / 查询足迹面积。正样本要求 coverage≥0.8、面积比≤4、中心距离≤sqrt(查询面积)；coverage≤0.05 才为负，其他忽略。完全覆盖的 1.5 倍边长候选可为正，即使 IoU≈0.444。多正样本共同训练。

地区划分由卫星 CRS 中的 GeoJSON 多边形规定，属性 `split=train/val/test`。查询和全部候选足迹需处于唯一分区的内缩缓冲内；分区之间再次检查候选足迹交会，同一个 group/sequence 不跨集合。只有 sequence 划分不足以通过检查。所有 DS/DV/NS/NV 使用同一套地理分区。地区不足时保留为数据限制，不报告地理泛化。

候选由原始先验或固定种子模拟先验生成。模拟协议对原始先验施加独立噪声，不利用 GT 定位候选，原始/模拟协议应分开运行与报告。高度扰动需要显式 reference_agl_m，以定义候选尺度随 AGL 的比例关系。仅示例的 3.7–5.6 km / 200 m 不能当作当前数据实测误差。

## 默认 MLP 模型与损失

本节描述默认冻结骨干的 MLP 路径。新增的在线 LoRA 备选路径见 [LoRA备选方案](LoRA备选方案.md)，共用前述数据、几何和划分约定，但不使用固定特征缓存。

冻结非 register DINOv2 ViT-L/14，336 输入，取 576×1024 patch tokens。GeM = normalize(mean(clamp(tokens,1e-6)^4)^(1/4))，float32 计算。两头独立参数，1024→512→GELU→Dropout(默认0)→512→L2 normalize。骨干只在提取期间 no_grad，MLP 正常反传。

当前实现 **单向组内多正样本对比损失**，不称为双向 InfoNCE：

`L_i = logsumexp(z_ij, j∈A_i) − logsumexp(z_ij, j∈P_i)`，`z_ij=dot(h_IR(q_i),h_sat(s_ij))/temperature`。

P 是该帧所有正例，A 为正例和选中的合法负例，ignore 不进分母。无正例查询仅在训练跳过，评估仍计入总体召回。每帧独立图库，无跨帧隐含负例，避免同位置其它图像被当负例。困难负例仅从 train 的合法负例挖掘，包括外观相似和地理近邻；列表定期缓存。四组均衡采样，验证 Recall@1 选 best，测试只最后运行。

缓存固定特征没有逐 epoch 像素增强。当前未启用额外增强视图或在线提取训练。提取进程独立加载 backbone，按 manifest 索引模 GPU 数分片，单组缓存原子落盘、重试、断点跳过、最终完整性合并；不使用 DDP/NCCL。单卡小测 OOM 时批量减半。

缓存包含原输入文件、配置、预处理代码、模型和源码指纹。配置变化需要新 manifest/cache，不会静默复用。评估使用同一个 manifest 与缓存比较 GeM1024 与 head512，输出所有合法查询召回、有正例查询的条件召回、覆盖率、首正例名次、候选数、分组统计。数据流失另列全量报告；几何失败不是可评价合法查询，但不能从数据流报告中隐藏。检索耗时与特征提取耗时分别记录，均不是最终 matching+DSM/PnP 定位精度。
